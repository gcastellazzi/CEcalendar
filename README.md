# CE Calendar

Calendario bilingue e di sola lettura per gli appelli del corso di laurea magistrale in Civil Engineering dell'Università di Bologna.

Il calendario è pubblicato su [gcastellazzi.github.io/CEcalendar](https://gcastellazzi.github.io/CEcalendar/).

Il sito legge i dati aggiornati dalla [pagina ufficiale degli appelli](https://corsi.unibo.it/2cycle/CivilEngineering/exam-dates) quando viene aperto o quando si preme **Aggiorna**. Gli intervalli mostrati hanno una durata indicativa di tre ore e servono esclusivamente a rendere visibili le sovrapposizioni.

## Funzioni

- viste mensile e settimanale;
- interfaccia italiana e inglese;
- filtri per corso e docente;
- evidenza visiva degli appelli sovrapposti;
- esportazione CSV e iCalendar (`.ics`);
- pubblicazione automatica su GitHub Pages.

## Sviluppo locale

Il progetto non richiede dipendenze o compilazione. Servire la cartella `dist` con un server HTTP locale, quindi aprire l'indirizzo indicato dal server.

## Fonte e avvertenza

CE Calendar è un visualizzatore indipendente. In caso di discrepanze fanno fede esclusivamente i dati pubblicati dall'Università di Bologna.
